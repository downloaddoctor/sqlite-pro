# Contributing

## Setup

```
pnpm install      # also points git hooks at .githooks
pnpm check        # typecheck + lint + format + tests
```

Node >= 22.13 and pnpm are required.

## Layout

- `src/` TypeScript sources. `src/index.ts` wires the store; the other modules own one concern each.
- `test/` node:test suites (`*.test.js`), run against the built `dist/`.
- `test-types/` compile-time tests for the public types.
- `scripts/` build, release, pack-check and API-doc helpers.
- `docs/API.md` is generated by `pnpm run docs` (plain `pnpm docs` is a built-in pnpm command) from `src/types.ts` and `src/index.ts`; never edit it by hand.
- `bench/` benchmark against raw `node:sqlite` (`pnpm bench`).

## Rules

- Keep runtime dependencies at zero.
- Public types live in `src/types.ts`; do not hand-write declaration files.
- Every behavior change needs a test and a `CHANGELOG.md` entry under `[Unreleased]`.
- Commit messages follow `<emoji> <type>(<scope>): <subject>`.

## Releasing

`pnpm release <patch|minor|major>` runs the gate, bumps the version, rolls the changelog, commits and tags. Push the tag to publish.
